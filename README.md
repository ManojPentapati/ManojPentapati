## 🌟 Featured Projects

### 🤖 [Agentic AI Code Analyzer](https://github.com/ManojPentapati/Agentic-Ai-Code_Analyzer-)
*A production-grade, multi-agent AI system built with **LangGraph** that performs intelligent, deep code review, security audits, and performance refactoring.*
* **Tech Stack:** Python, LangGraph, LangChain, Groq (Llama 3.3), Streamlit, Ruff Linter, FPDF2.
* **Key Achievements:**
  * Orchestrated a 5-agent pipeline with dynamic routing based on complexity metrics and security scans.
  * Designed custom tools for language detection, code security vulnerability checks, and AST parsing.
  * Generates high-quality PDF code reports and provides an interactive side-by-side Git-style code diff.

### 🚗 [Real-Time Object Tracking System](https://github.com/ManojPentapati/Object-Tracking-System)
*A computer vision application with a graphical interface that detects and tracks multiple moving objects in real-time.*
* **Tech Stack:** Python, YOLOv5, SORT Algorithm, OpenCV, Tkinter.
* **Key Achievements:**
  * Implemented YOLOv5 object detection combined with the SORT (Simple Online and Realtime Tracking) tracking algorithm for ID preservation across video frames.
  * Built a user-friendly desktop GUI using Tkinter for custom video uploading and visual debugging.

### 📊 [Pizza Sales Business Intelligence Analysis](https://github.com/ManojPentapati/Pizza-Dataset-Analysis-Using-My-Sql)
*An end-to-end database analysis modeling project optimizing business transactions and sales performance.*
* **Tech Stack:** MySQL, Relational Database Modeling, Advanced SQL Queries (CTEs, Window Functions, Joins).
* **Key Achievements:**
  * Analyzed a dataset of **21K+** orders to extract critical KPIs including order frequencies, peak times, and revenue drivers.
  * Formulated query structures that reduced processing bottlenecks and outputted comprehensive business dashboard reports.
